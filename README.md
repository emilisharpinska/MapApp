# 🗺 MapApp

Simple iOS application that demonstrates working with maps and user location using MapKit.

---

## 🎯 Purpose
This project was created to deepen understanding of iOS map-based applications and geolocation services.  
It demonstrates practical usage of MapKit and CoreLocation, as well as building responsive UI with SwiftUI following MVVM principles.

---

## 📱 Features
- Display user location on the map  
- Show map with interactive region  
- Add and display annotations (pins)  
- Basic map interactions (zoom, move)  

---

## 🛠 Tech Stack
- Swift  
- SwiftUI  
- MapKit  
- CoreLocation

---

## 🧠 Architecture
- MVVM (basic implementation)  

---

## 📍 Functionality
- Access and display current user location  
- Handle location permissions  
- Update map region dynamically  
- Work with map annotations
